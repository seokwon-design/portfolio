규칙은 단단하게,
시작은 가볍게.이해하기 전에 먼저 즐기게 되는 성장 구조를 설계합니다. 처음엔 가볍게 시작하고, 오래 할수록 파고들 깊이가 있어야 한다고 생각합니다.

유저 행동, 핵심 로직, 데이터 구조를 연결해 설계합니다. 여러 유저가 공통으로 원하는 요소를 잡아내, 협업 부서가 같은 기준으로 판단할 수 있는 규칙과 정책으로 옮기는 데 강점이 있습니다.

AI로 기획과 개발에 드는 시간이 크게 줄어든 지금, 더 중요한 건 무엇을, 왜 만들어야 하는가라고 생각합니다. 기획서 작성과 반복 작업은 Claude · Claude Code로 빠르게 처리하고, 아낀 시간은 무엇을 기획할지 고민하고 AI가 만든 결과를 비판적으로 다시 검증하는 데 씁니다.

Cover Letter

수집·성장 시스템을 설계하는 기획자

니즈게임즈에서 수집·성장 시스템과 전투 콘텐츠를 기획하고 있습니다. 다크디셈버에서는 개발부터 글로벌 런칭까지 장비 강화, 에테르 코어, 가챠 상자, 차원 균열: 벨레스를, 언디셈버 라이브에서는 룬캐스트 프리셋과 시간의 성좌 통폐합, 침식의 공세를 맡아 신규 설계와 라이브 개편을 모두 경험했습니다.

규칙과 수치, 예외 정책, 데이터 테이블까지 직접 설계하며, 최근에는 Claude와 Claude Code를 실무에 들여 기획서 작성부터 데이터 작업까지 일하는 속도를 바꾸고 있습니다.

쉽게 시작하고, 깊게 빠지는 성장 구조

수집·성장 시스템은 처음엔 가볍게 시작하고, 오래 할수록 파고들 깊이가 있어야 한다고 생각합니다. 신규 개발에서는 이 구조를 처음부터 설계했고, 라이브에서는 기존 아이템과 획득 기록, 미수령 보상까지 전환하며 규칙이 유저의 플레이로 이어지는 과정을 끝까지 책임졌습니다.

이제 더 넓은 범위의 시스템과 콘텐츠에서 이 경험을 쓰고 싶습니다. AI로 작성과 반복 작업에 드는 시간을 줄인 만큼, 그 시간을 설계와 검증에 더 쓰는 기획자로 기여하겠습니다.

다수가 원하는 것을, 구현 가능한 규칙으로

다수가 원하는 것을 짚어냅니다. 여러 유저가 공통으로 원하는 요소를 잡아내 시스템에 반영합니다. 시즌마다 별도 파밍이 부담된다는 오랜 요구를 시간의 성좌 통폐합으로 풀어, 카오스 던전 파밍 중에 성장 보상을 함께 얻도록 바꿨습니다.

규칙과 데이터로 설계합니다. 기능을 화면이 아니라 규칙·수치·예외·테이블 구조로 정의합니다. 누가 읽어도 같은 결과를 구현하고 검증할 수 있는 기획서를 기준으로 삼습니다.

엔진까지 직접 다룹니다. UE4 위젯 블루프린트 구조 설계와 레벨·스폰·몽타주 세팅까지 직접 다루며, 기획한 규칙이 실제 화면과 전투에서 어떻게 동작하는지 손으로 확인합니다.

AI 시대, 무엇을 만들지 더 깊이 고민합니다. 기획서 작성과 정책 문서 구조화는 Claude를 활용하고, 복잡하고 반복되는 작업(VBA·P4V 스크립트와 데이터 일괄 수정, 기획서 기반 구현)은 Claude Code로 처리합니다. 만드는 시간이 짧아진 만큼 '무엇을, 왜 만들어야 하는가'를 더 깊이 고민하고, AI가 만든 결과는 그대로 받아들이지 않고 비판적으로 다시 검증합니다.

팀의 속도를 함께 올리는 기획자

입사 후에는 담당 게임의 시스템 구조와 데이터, 유저 동선부터 파악해 설계 의도를 정확히 이해하겠습니다. 신규 시스템은 기존 구조와의 연결과 예외까지 정의하고, 라이브에서는 지표와 유저 반응을 근거로 개선을 제안하겠습니다.

제가 다듬어 온 AI 활용 방식도 팀과 공유해 반복 작업을 함께 줄이고, 장기적으로는 성장 구조 전체를 설계하는 기획자가 되겠습니다.
